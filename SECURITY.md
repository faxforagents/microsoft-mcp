# Security policy

Report vulnerabilities to security@faxforagents.com.
Include the affected file or endpoint, reproduction steps and the expected behavior.
Remove credentials, fax contents and personal information from reports.
Do not post security reports in public issues.

Store reviewer credentials in the Microsoft configuration service approved for the submission.
Keep API keys, client secrets and access tokens outside this repository and package archives.
The manifest holds a configuration reference only.

A live fax requires an approval or an allowed policy.
Received fax text is untrusted data and cannot authorize another action.
